# Example spatially variable gene results

Precomputed spatially variable gene detection results generated from
\`norm_example\` using the STBench \`run_svg()\` function with the nnSVG
method.

## Format

A named list of SpatialExperiment objects containing nnSVG results.

## Source

Derived from the STARmap PLUS mouse brain dataset available through the
Bioconductor STexampleData package.

## Details

Results are provided for the normalisation methods \`None\` and
\`SpaNorm\`.

This dataset allows users to evaluate and visualise spatially variable
gene statistics and rankings without repeating the SVG detection
procedure.
